# Posted Receipt Guidance Design

## Request

ปรับข้อความคำแนะนำในหน้ารายละเอียดใบรับเข้า สำหรับใบรับเข้าที่บันทึกเข้าคลังแล้ว เพื่อให้ผู้ใช้เข้าใจข้อจำกัดและเส้นทางแก้ไขยอดได้ทันที

## Problem

ข้อความเดิมใช้คำภาษาอังกฤษว่า “Posted” และ “ledger” และใช้คำว่า “ปรับยอด/รับคืน” โดยไม่ได้อธิบายขั้นตอนให้สอดคล้องกับปุ่มจริงบนหน้ารายการน้ำยา ผู้ใช้อาจไม่ทราบว่าใบรับเข้าเดิมแก้ไขไม่ได้ หรือไม่รู้ว่าต้องเปิดรายการน้ำยาจากตารางด้านล่าง

## Design

คงกล่องคำแนะนำไว้เฉพาะเมื่อใบรับเข้าอยู่ในสถานะบันทึกเข้าคลังแล้ว แต่เปลี่ยนเป็นข้อความภาษาไทยที่สั้นและนำไปปฏิบัติได้:

> ใบรับเข้านี้บันทึกเข้าคลังแล้ว จึงแก้ไขประวัติเดิมไม่ได้ หากยอดไม่ตรง ให้คลิกชื่อน้ำยาด้านล่าง แล้วเลือก “ปรับยอดคงคลัง” เพื่อเพิ่มหรือลดยอด พร้อมระบุเหตุผลทุกครั้ง

ข้อความนี้จะ:

- บอกสถานะและข้อจำกัดว่าไม่สามารถแก้ไขประวัติเดิมได้
- ชี้เส้นทางจากตารางรายการน้ำยาไปยังหน้าที่มีปุ่ม “ปรับยอดคงคลัง”
- ใช้ “เพิ่มหรือลดยอด” เพื่อครอบคลุมกรณียอดคลาดเคลื่อนและรับคืน โดยไม่อ้างถึงปุ่มที่ไม่มีอยู่จริง
- ย้ำว่าต้องระบุเหตุผลทุกครั้ง เพื่อรักษาความตรวจสอบย้อนหลังได้ของรายการเคลื่อนไหว

## Scope

- เปลี่ยนเฉพาะข้อความใน `app/(protected)/receipts/[id]/page.tsx`
- คงเงื่อนไขการแสดงข้อความเฉพาะสถานะ `posted`
- คงรูปแบบ `inline-alert inline-alert--info`, `role="note"` และลิงก์ชื่อน้ำยาเดิม
- ไม่เปลี่ยนฐานข้อมูล การคำนวณยอด สิทธิ์ หรือขั้นตอนการปรับยอด

## Accessibility and interaction

- คงองค์ประกอบย่อหน้าและ `role="note"` เพื่อให้คำแนะนำถูกประกาศเป็นหมายเหตุโดยเทคโนโลยีช่วยเหลือ
- ไม่เพิ่มการโต้ตอบใหม่ในกล่องข้อความ เพราะชื่อน้ำยาในตารางเป็นจุดนำทางที่มีอยู่แล้ว
- ใช้ชื่อปุ่มภาษาไทยตามหน้าปลายทาง เพื่อให้ผู้ใช้ตามคำแนะนำได้ตรงกับหน้าจอจริง

## Verification

- เพิ่มการตรวจใน `scripts/receiving-ui.test.ts` ว่าข้อความใหม่ใช้คำภาษาไทยและมีคำแนะนำเรื่อง “ปรับยอดคงคลัง” กับการระบุเหตุผล
- รัน `npm run test:receiving`
- รัน `npm run lint` และ `npm run typecheck`
- ตรวจ diff ให้แน่ใจว่าเปลี่ยนเฉพาะข้อความและการทดสอบที่เกี่ยวข้อง
