ข้อมูลลับจะถูกเข้ารหัสไว้ใน Windows ของผู้ใช้คนนี้ และไม่ถูกส่งผ่านเว็บแอป การตั้งค่าชุดเดียวใช้กับฐานข้อมูล Production ร่วมของ Stock และ Portal

กำหนดปลายทางและรอบเวลาของโปรเจคนี้

ไฟล์จะอยู่ในโฟลเดอร์ Production เดียวกันเพื่อไม่ให้สำรองซ้ำ ค่าแนะนำคือเก็บไว้ 30 วันและสำรองเดือนละครั้งเวลา 02:00 น.

ต้องติดตั้ง PostgreSQL client ที่มี pg_dump.exe ก่อนจึงจะสร้างไฟล์ได้ แอปจะไม่อัปโหลดไฟล์ dump ขึ้น cloud
